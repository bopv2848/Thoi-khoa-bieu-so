# Thời Khóa Biểu Số Thông Minh

Ứng dụng Web App thời khóa biểu thông minh, trực quan và hiện đại dành cho học sinh, giáo viên và nhà trường.

## ✨ Tính năng nổi bật

- 🎨 **Giao diện hiện đại**: Hỗ trợ chế độ Sáng / Tối (Dark / Light Theme), thiết kế thẩm mỹ cao với Tailwind CSS.
- 🌈 **Màu sắc trực quan**: Phân biệt màu sắc cho từng môn học giúp dễ dàng nhận diện và ghi nhớ.
- 📱 **Hỗ trợ PWA / Web App**: Trải nghiệm mượt mà trên cả máy tính, máy tính bảng và điện thoại thông minh.
- ⏱️ **Theo dõi tiết học thông minh**: Đánh dấu tiết học đang diễn ra theo thời gian thực.
- 🚀 **Hoạt động độc lập**: Chạy trực tiếp từ trình duyệt mà không cần cài đặt backend phức tạp.

## 📂 Cấu trúc thư mục

- index.html: Phiên bản chạy chính (hỗ trợ triển khai nhanh lên GitHub Pages / Web Hosting).
- Thời Khóa Biểu Thông Minh.html: Tệp nguồn gốc của ứng dụng.
- README.md: Hướng dẫn và tài liệu dự án.

## 🌐 Triển khai lên GitHub Pages

Để kích hoạt website trực tuyến miễn phí:
1. Vào repository trên GitHub: Settings > Pages.
2. Tại mục **Branch**, chọn nhánh main và thư mục / (root).
3. Nhấn **Save**. Trang web sẽ được xuất bản tại https://bopv2848.github.io/Thoi-khoa-bieu-so/.
